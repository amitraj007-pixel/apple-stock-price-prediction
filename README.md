# 🍎 Apple Stock Price Prediction

## 📌 Project Overview
Apple Stock Price Prediction is a Machine Learning-based project designed to analyze and predict Apple (AAPL) stock prices. The project combines Machine Learning with a web-based interface to make stock price prediction more accessible.

## 🛠️ Technologies Used
- Python
- Machine Learning
- React.js
- FastAPI
- Streamlit

## 📂 Project Structure
- **backend/** – Backend implementation
- **frontend/** – React-based frontend
- **streamlit_app/** – Streamlit application

## 🎯 Project Objective
The main objective of this project is to explore stock market data and apply Machine Learning techniques for Apple stock price prediction.
